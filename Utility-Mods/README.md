# Utility Mods

This folder is for **utility mods** — quality-of-life, tools, automation, storage,
and other helpful mods that make playing easier.

Drop mod files (or links to them) in this folder and keep the list below updated.

## Mod List

| Mod | Version | Minecraft Version | Link | Notes |
| --- | ------- | ----------------- | ---- | ----- |
| _Example: Inventory HUD+_ | _1.20.1_ | _1.20.1_ | _[link](https://example.com)_ | _Shows inventory on screen_ |

## How to add a mod

1. Add the mod file to this folder, or paste its download link in the table.
2. Add a row to the table above with the mod name, version, and Minecraft version.
3. Commit and push so it shows up on GitHub.

# Utility Mods

This folder is for **utility mods** — quality-of-life, tools, automation, storage,
and other helpful mods that make playing easier.

## Mod List

| Mod | Version | Minecraft Version | Link | Notes |
| --- | ------- | ----------------- | ---- | ----- |
| _Example: Inventory HUD+_ | _1.20.1_ | _1.20.1_ | _[link](https://example.com)_ | _Shows inventory on screen_ |

## How to add a mod into Minecraft

Find .minecraft folder, and then mods folder, and then put .jar inside. Or use something like Prism Launcher.
